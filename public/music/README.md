# Background Music Guide

Place your legally licensed romantic instrumental background music MP3 in this directory:

File path: `public/music/romantic_instrumental.mp3`

Suggested genres:
- Traditional Maharashtrian Shehnai, Sitar, Flute or Santoor instrumental.
- Soft romantic acoustic classical melody.

Note:
If no MP3 file is present, the website's built-in Web Audio ambient chime will gracefully synthesize peaceful traditional notes (Bhopali / Mohanam scale) upon user interaction.
